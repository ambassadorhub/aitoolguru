**What It Does:**

ChatGPT is OpenAI's conversational AI that handles writing, coding, analysis, brainstorming, and customer communication. The free tier is generous, and GPT-4o offers near-instant responses with improved reasoning.

**Key Features:**

- Natural language conversations for any business task
- Code generation and debugging
- Document analysis and summarization
- Custom GPTs for specialized workflows
- API access for integration into your own tools

**Pricing:**

- Free: GPT-4o mini, limited GPT-4o access
- Plus: £16/month for full GPT-4o, higher limits, priority access
- Team: £20/user/month for workspace features

**Verdict:** The default choice for UK small businesses. Start with free, upgrade when you hit limits. Essential for content creation, customer support drafts, and productivity automation.
